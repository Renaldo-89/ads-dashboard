KETIGA

Pesanan sampai atau tidak?

Status pengiriman dan pencairan cashback per pesanan.

Salinan repo di MacBook, tempat skrip Everpro dijalankan.

Kenapa perlu Worker

Browser tidak boleh memanggil API Windsor.ai atau Globemerce secara langsung karena aturan lintas-domain, dan token tidak boleh ditanam di halaman publik. Worker menjadi perantara: token disimpan sebagai rahasia di Cloudflare, halaman hanya memanggil Worker.

Catatan sejarah Everpro

Semula Everpro ditarik memakai token sesi dari browser. Cara itu gagal dari Cloudflare Worker karena dashboard pelanggan Everpro dilindungi Bot Management dan menjawab permintaan dari pusat data dengan halaman tantangan "Just a moment...", sehingga penarikan sempat dijalankan lewat skrip Python di MacBook.

Sejak tersedianya Everpro Open API, cara itu ditinggalkan. Worker kini menukar sendiri client key dan client secret menjadi token berumur 24 jam, lalu memanggil endpoint resmi. Tidak ada lagi token yang perlu disalin manual, dan MacBook tidak perlu menyala.

Kolom rujukan

client_order_no, shipment_order_no, unique_reference_id, logistic_reference_number.

Kiriman berstatus dibatalkan disaring dari tampilan, dari perhitungan, dan dari pencocokan. Berkasnya tetap menyimpan lengkap, penyaringan hanya di sisi tampilan.

Keputusan privasi. Repository bersifat publik, maka nama, nomor telepon, dan alamat pembeli tidak pernah disimpan ke dalamnya. Berkas Everpro hanya memuat resi, nomor order, status, dan nominal. Nama pembeli ditampilkan di dashboard dengan mengambilnya dari Globemerce secara langsung saat halaman dibuka, lalu dicocokkan lewat nomor resi atau nomor order. Hasil akhirnya sama informatifnya, tanpa menerbitkan data pribadi pelanggan.

9Operasi rutin

Memperbarui dashboard setelah ada perubahan berkas

cd ~/Documents/ads-dashboard
git add . && git commit -m "keterangan perubahan"
git pull --rebase && git push

Selalu commit dulu baru git pull --rebase, karena robot GitHub rutin menulis data ke repo yang sama dan bisa membuat push ditolak.

Menyegarkan data

Tidak ada langkah manual. Semua sumber ditarik saat dashboard dibuka. Tombol muat ulang di kartu profil memaksa mengambil data baru dengan melewati simpanan sementara.

Memperbarui kode Worker

Cloudflare → Compute → Workers & Pages → ads-proxy → Edit code → pilih semua, hapus, tempel isi worker.js → Deploy.

Menambah akun atau platform iklan baru

Otorisasi di Windsor.ai, lalu tidak perlu mengubah kode apa pun — daftar akun dan platform dibangun otomatis dari data yang masuk.

10Batasan dan catatan

  • Data tidak real-time. Google Ads sendiri tertinggal beberapa menit sampai beberapa jam, dan Windsor menyalinnya menurut jadwalnya sendiri. Konversi paling lambat karena menunggu jendela atribusi.
  • Token Globemerce bisa mati. Globemerce masih memakai token sesi browser, bukan API key resmi. Bila data penjualan berhenti masuk, itu penyebab pertama yang perlu dicek. Meminta API resmi ke Globemerce adalah perbaikan berikutnya yang paling berharga — Everpro sudah melewati tahap ini.
  • Nomor order tidak selalu tercatat. Penggabungan dengan Globemerce mengandalkan nomor order yang disisipkan di catatan Everpro. Sejauh ini hanya kiriman instan seperti GoSend yang mencantumkannya; sisanya dicocokkan lewat nomor resi.
  • Windsor.ai berstatus percobaan. Bila masa trial habis, seluruh data iklan berhenti mengalir.
  • Laporan Auction Insights milik Google yang membandingkan dengan domain pesaing tidak tersedia lewat Windsor. Analisis lelang memakai metrik pangsa tayang resmi, yang inti diagnosanya sama tetapi tanpa nama pesaing.
  • Meta Ads, TikTok Ads, dan TikTok Shop sudah disiapkan penuh di kode, tinggal diotorisasi. ROAS gabungan baru bisa dihitung setelah ada sumber omzet yang tersambung.
